# bblove-law-open

법제처 국가법령정보 공동활용 OPEN API(DRF)로 대한민국 현행 법령 원문을 수집해 검증한 뒤 GitHub Release로 게시하는 공개 저장소입니다.

- **출처**: 법제처 국가법령정보 공동활용(law.go.kr DRF). 법령·판결 등은 저작권법 제7조의 보호받지 못하는 저작물입니다.
- **게시물**(Releases): 각 게시에는 `release-info.json`(형식 버전·출처 커밋·파일별 SHA-256), `SHA256SUMS`, GitHub 빌드 출처 증명(attestation)이 붙습니다.
  - `law-YYYYMMDD-<run_id>`: 현행 법령·시행령·시행규칙 원문(매주)
  - `admrul-YYYYMMDD-<run_id>`: 행정규칙(매주)
  - `prec-YYYYMMDD`: 판례·국세청 법령해석·조세심판원 결정 **요지**(판결 전문 미포함). 여러 날에 걸쳐 이어 받고, 완료 후 기본 1일 간격으로 신규 ID만 확인해 신규 문서가 있을 때 게시. 조각 파일은 `cat precedent-collection.tar.gz.part-* | tar -xz`로 풉니다.
    - 항목별 `kind`: `detail`(법제처 상세 요지 — 데이터출처 '대법원' 판례, 조세심판원 결정), `listing`(목록 행만 — 데이터출처 '국세법령정보시스템' 판례와 국세청 법령해석은 법제처 상세 조회가 없음), `skipped`(그 밖의 데이터출처, 예: 사건번호·선고일이 비어 있는 근로복지공단 판례 — 요청하지 않음).
    - 실패는 항목별 고정 코드로 남습니다(예: 선고일이 수집일 이후 `DATE_IN_FUTURE`, 상세에 판시사항·판결요지가 없는 하급심 `SUMMARY_EMPTY`). 기존 문서 상태·요지는 보존하며 새 판결 ID만 추가합니다. 목록에서 기존 ID만 있는 첫 페이지를 만나면 안전 확인용 한 페이지를 더 조회하고 멈춥니다.
- **검증**: 수집 후 조문 수·식별자·시행일 검사와 자산 빌드 검사를 통과한 수집본만 게시합니다. 실패 목록(`collection-failures.json`)도 함께 게시합니다.
- **범위 밖**: 이 저장소는 수집 코드와 공공 법령 데이터만 다룹니다. 개인 정보, 질의 내용, 인증값은 넣지 않습니다.

공식 원문 확인은 항상 [국가법령정보센터](https://www.law.go.kr)에서 하십시오.

행정규칙 HTML 본문은 텍스트로 변환합니다. `script`·`style`·`iframe`·`object`는 내용까지 제거하고,
이미지는 `[이미지]` 또는 `[이미지: 대체 텍스트]`로 표시합니다. 링크 주소와 이벤트 속성은 남기지 않습니다.
이미지 표시에만 의존하는 문서는 빈 본문으로 실패 처리합니다. 표·서식 이미지의 내용과 배치는 공식 원문에서 확인하십시오.
수집 매니페스트 schema 2의 문서별 `images_removed`·`scripts_removed`는 본문과 부칙에서 파싱된
`img`·`script` 시작 태그 수입니다(제거 영역 내부 포함, script/style 문자열 내부의 가상 태그 제외).
실패 전까지 집계한 수도 남으며, 아직 처리하지 않은 PENDING 문서의 0은 검사가 끝났다는 뜻이 아닙니다.
원본 JSON은 그대로 보존하며, 기존 체크포인트를 재사용해도 제거 건수는 다시 계산합니다.
